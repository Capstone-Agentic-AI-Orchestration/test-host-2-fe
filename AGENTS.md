# AGENTS.md: test-host-2-fe

Project memory for agents working in this repository. Read it before changing anything. Keep it short and true; update it in the same pull request when a fact here changes.

## What this is
- The **frontend** of the "Hosting Test Project" project in Alpha. Its backend is `test-host-2-be`.
- React 19 + TypeScript, built with Vite 6. Entry: `src/main.tsx` renders `App` from `src/App.tsx` into `#root` in `index.html`.

## Run and check
- `npm install`, then `npm run dev` (Vite on port 5173, `strictPort`: it fails instead of moving to another port).
- Before a pull request: `npm run typecheck`, `npm run lint` (`src` and `tests`), `npm test`.
- `npm run build` type-checks, then writes `dist/`.

## Backend connection
- The backend URL comes from `VITE_API_URL` (see `.env.example`; locally the backend runs on port 3000). Only `VITE_`-prefixed variables reach the browser.
- Never hard-code backend URLs, hosts or keys; read them from env.
- The backend allows browser calls only from origins in its `CORS_ORIGINS`; this app's dev origin is `http://localhost:5173`.

## Tests
- Jest + ts-jest. Unit tests live in `tests/unit/`, mirror `src/`, and end in `.spec.tsx` / `.spec.ts`.
- End-to-end suites go in `tests/e2e/` as `*.e2e-spec.ts` so the unit run skips them.

## Branches and CI
- Work lands on `dev`, then is promoted to `uat` and `main`, by pull request only. Never push to those branches directly.
- `.github/workflows/ci.yml` (generated by Alpha from the shared alphaorch-workflow template) runs tests with coverage (threshold 10%), lint and a security scan on pushes and PRs to `dev`, `uat` and `main`. Do not edit it by hand.
- Hosting is Vercel, set up by Alpha; it deploys from GitHub, so CI holds no deploy secrets.

## Rules
- This repository is public: never commit secrets, tokens or real customer data. `.env` is git-ignored; copy `.env.example`.
- Commit `package-lock.json` whenever dependencies change.
